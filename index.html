▼ 用語集

つまずきやすい言葉を、やさしく

マニュアルに出てくる言葉の意味を、まとめました。分からない言葉が出てきたら、ここへ戻ってきてください。

Skill（スキル）
Claudeに渡す、仕事の取扱説明書。手順や品質の基準が書かれたフォルダーで、必要なときに読みに行って使います。
SKILL.md
Skillの中心になるファイル。名前、説明、進め方が書かれています。Skillを入れるときは、このファイルがあるフォルダーごとコピーします。
Claude Code
パソコンで動かす、Claudeのコーディング・作業用のツール。この資料のSkillは、ここで使う前提です。
リポジトリ
GitHub上で、ファイルや変更の履歴をまとめて保管している場所。今回は、Skillの配布元として使います。
GitHub（ギットハブ）
プログラムや資料を公開・共有するサービス。ここからZIPで取得します。
ZIP / 展開
複数のファイルをひとまとめに圧縮した形式がZIP。使うときに元のフォルダーの形に戻すのが「展開」です。
コミット
リポジトリの、ある時点の状態を記録したもの。コミットを固定すると、確認した内容を、そのまま再現できます。
フォルダー（ディレクトリ）
ファイルを入れておく入れ物。Skillはフォルダー単位で置きます。
プロジェクト
特定の仕事のための作業フォルダー。プロジェクト用のSkillは、その中の .claude/skills に置きます。
ターミナル
文字で命令を入力する画面。PowerShellやBashなどがあります。この資料のコピー手順は、手動でもできます。
/skills
Claude Codeで、使えるSkillの一覧を表示するための入力。導入したSkillが認識されたかの確認に使います。
/reload-skills
新しく置いたSkillを、再起動せずに読み込み直すための入力。対応していない版では、Claude Codeの再起動を。
LP（ランディングページ）
商品や講座を紹介して、申し込みなどの行動につなげる、1ページ完結のWebページ。
ローカル
自分のパソコンの中だけで動かしている状態。公開前の確認は、ここで行います。
ホスティング
作ったWebページを、インターネット上に公開するための場所を借りること。この資料では、別途の設定です。
Playwright
ブラウザを自動で操作して、画面の確認ができるツール。webapp-testingがPython版を使います。
Python
プログラミング言語の1つ。webapp-testingやskill-creatorの補助ツールの実行に使います。
MCP
Claudeが外部のサービスとつながるための仕組み。実際の予約投稿など、Skillだけではできないことを補います。
API
ソフトウェア同士がやり取りするための窓口。外部サービスへの投稿などで使われます。
ライセンス（MIT / Apache-2.0）
使ってよい条件を示すもの。今回のSkillは、MITとApache-2.0。ライセンスのファイルは、消さずに一緒に残します。
依存関係
動かすために、別途必要なもの。例えば、webapp-testingのPythonやPlaywrightです。
ダミーデータ
実在しない、試験用の情報。個人情報の代わりに使って、安全に動作を確認します。
WSL
Windowsの中でLinux環境を動かす仕組み。保存先やコマンドが、Windowsネイティブとは別になります。
claude CLI
ターミナルから使う、Claudeの命令実行ツール。skill-creatorの説明文の自動評価で使い、利用枠を消費します。

▼ 概要

このSkillでできること

ブログ、ニュースレター、無料配布コンテンツ。発信を始めると、すぐにぶつかるのが「次は何を書こう」という悩みです。content-strategyは、記事の柱、関連テーマ、優先順位、再利用の方針を整理するSkillです。

企画の段階で使うので、書く作業そのものの前に出番があります。product-marketingで作った商品資料と組み合わせると、商品へつながる発信テーマが見えやすくなります。

検索数や競合の実績といった数字は、実データがあって初めて意味を持ちます。このSkillは企画の骨組みを作る係。数字は人が用意する、と覚えておくと使い分けやすいです。

▼ 使う場面

こんなときに頼れます

ネタ切れで手が止まったとき

テーマの柱を先に決めておけば、毎回ゼロから考えずに済みます。

4週間分をまとめて決めたいとき

週ごとの狙いを決めて、発信を1本の流れにします。

無料配布から講座案内へつなげたいとき

疑問への回答、無料資料、案内という順番を設計します。

1本の記事をほかでも使い回したいとき

再利用の方針も企画に含めておくと、あとのSNS展開がスムーズです。

▼ 使う前の準備

用意しておくと、仕上がりが変わります

商品資料がなくても使えます。その場合は、商品と読者の情報を指示に書き添えましょう。

▼ 概要

このSkillでできること

Python版のPlaywrightを使って、ローカルのWebアプリを実際に操作しながら確認するSkillです。ボタンの動作、画面表示、ブラウザのログ、スクリーンショットの確認に使えます。

LP制作のあとに入れると効果的。人の目だと見落としやすい「スマホ幅での崩れ」や「入力エラーの出方」を、まとめて点検できます。

フォルダーをコピーしただけでは動きません。Python、Playwright、対応ブラウザーなどの準備が別に必要で、7つの中では手間のかかる部類です。ほかのSkillに慣れてから取り組むと、つまずきにくいでしょう。
